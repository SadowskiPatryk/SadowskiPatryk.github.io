# Patryk Sadowski: Personal Portfolio & Resume

A lightweight, responsive, and evergreen personal portfolio/resume website built with clean HTML5, Tailwind CSS, and Vanilla JavaScript. Features dark/light mode, simple bilingual support, SEO optimization, and AI-agent compatibility.

---

## Features

- **Zero-Build Architecture:** Single-file HTML structure powered by Tailwind CSS via CDN — no framework overhead.
- **Bilingual Support (EN/PL):** Instant language switching with smooth fade animations and `localStorage` persistence (defaults to English).
- **Dark & Light Mode:** Seamless theme toggle with CSS transitions.
- **SEO & Social Media Ready:** Complete metadata, `sitemap.xml`, and `robots.txt`.
- **AI-Agent Compatible:** Includes `llms.txt` structured Markdown context for AI models and crawlers.
- **GitHub Pages Hosted:** Automated deployment via GitHub Pages.
